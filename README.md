# TurboForms

TurboForms is a modern form builder platform inspired by Typeform, built with the PERN stack and designed for creating dynamic, shareable, and customizable forms.

Currently under active development 🚧

## Features

- Dynamic form creation
- Multiple field types
- Public & unlisted forms
- Form validation
- Shareable form links
- Response collection & analytics
- Authentication system
- API documentation
- Theme support
- Creator dashboard

## Tech Stack

### Frontend
- React
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- PostgreSQL
- Drizzle ORM
- Zod
- JWT Authentication
- Multer
- Cloudinary

### API & Docs
- Scalar OpenAPI
- Swagger


## Note 
The goal is to build a scalable production-style form builder while learning and shipping in public.

More features, documentation, and setup instructions will be added as development progresses.
